# Provenance

Byte-exact copy of `docutils/parsers/rst/include/` from the pinned docutils
0.22.4 wheel (the wave's parity oracle), embedded via `include_str!` so the
`include` directive's standard-include form (`.. include:: <isonum.txt>`)
resolves without a docutils installation. The data files are placed in the
public domain (see each file's header and `README.rst` beside this note);
docutils itself is BSD-2-Clause/GPL/PSF-licensed, which permits this
redistribution. Do not edit these files — refresh them from the pinned wheel.
